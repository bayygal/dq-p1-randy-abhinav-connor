# dq-p1-randy-abhinav-connor

This repository has been initialized as a minimal Python project scaffold.

## Getting started

1. Create and activate a virtual environment.
2. Install dependencies:
   `python -m pip install -r requirements.txt`
3. Run the package:
   `python -m dq_p1_randy_abhinav_connor`
4. Run tests:
   `python -m pytest`

## Project layout

- `src/dq_p1_randy_abhinav_connor/` — source package
- `tests/` — automated tests
- `pyproject.toml` — project metadata and packaging configuration
